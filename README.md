## 🎮 The Persona 3 Reload Portfolio Experience

This portfolio is not a standard static website — it is built from the ground up as an interactive JRPG command console featuring:

### 1. 🌊 "Sinking into the Heart" Aesthetic & Design System
- **Authentic P3 Color Tokens**: Deep Tartarus Midnight (`#040B22`, `#050C24`), Electric Cyan (`#00D2FF`), S.E.E.S. Evoker Crimson (`#FF1E44`), Arcana Gold (`#FFE600`), and Dark Hour Green (`#39FF14`).
- **Dynamic Underwater Canvas**: Real-time canvas rendering of swimming light caustics and deep-sea particles echoing the Persona 3 Reload main menu.
- **Iconic Angular Architecture**: Skewed menus (`transform: skewX(-8deg)` to `-12deg`), tactile button cut-ins, high-contrast borders, and authentic arcade drop shadows.
- **Bespoke Persona Typography**: Built using Google Fonts **Teko** (tall compressed battle headers), **Rajdhani** (tactical HUD telemetry), and **JetBrains Mono** (terminal code output).

### 2. ⚔️ S.E.E.S. Party Status & Dynamic EXP Level System
- **Real-Time Level & HP/SP HUD**: Aman's party card in the top bar displays dynamic stats calculated via RPG progression curves.
- **Level Progression**: Clicking skills, testing simulators, or exploring tabs grants `+100 EXP`!
- **Level Up Fanfare**: Leveling up fires celebratory party confetti cannons and haptic pulse feedback.
- **Reload Reset**: Stats calibrate fresh on every reload, recalculating live session engagement.

### 3. 🌑 Astronomical Moon Phase & Dark Hour Clock

## 🚀 How to Run Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0 or higher recommended)
- `npm` or `yarn` / `pnpm`

### Step 1: Clone the Repository
```bash
git clone https://github.com/IamAGhoul007/portfolio.git
cd portfolio
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Start the Vite Development Server
```bash
npm run dev
```

The application will start locally at:
```
➜  Local:   http://localhost:5173/
```

### Step 4: Build for Production
To create an optimized production build:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```

## 🌐 1-Click Deployment

This project outputs cleanly to the `dist/` directory with relative asset resolution (`base: './'`), making it ready for zero-config hosting on:

### Vercel
1. Push your code to GitHub.
2. Import the project into [Vercel](https://vercel.com).
3. The included [`vercel.json`](file:///d:/port/vercel.json) will automatically configure the build (`npm run build`, output: `dist`).

### GitHub Pages
1. In your GitHub repository, navigate to **Settings > Pages**.
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. Push to `main` — the workflow in `.github/workflows/deploy.yml` will automatically build and publish the site.

### Netlify
1. Connect your repository on [Netlify](https://netlify.com) or drag-and-drop the `dist/` folder.
2. Build command: `npm run build`, Publish directory: `dist`.
